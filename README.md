# Evelyn — GitHub Copilot Skill

This is the **Evelyn** skill, rewritten for GitHub Copilot.

## Install

### Project skill (shared with the repo)
```bash
mkdir -p .github/skills/evelyn
# copy SKILL.md into that folder
```
Path: `.github/skills/evelyn/SKILL.md`

### Personal skill (all your repos)
```bash
mkdir -p ~/.copilot/skills/evelyn
# copy SKILL.md into that folder
```

## Download
- Clone: `git clone https://github.com/Cowlsly/evelyn-copilot-skill.git`
- Or download the ZIP from the green **Code** button on the repo page.

## Usage
Once installed, just talk to Copilot like normal. Say "Evelyn" or ask for help uploading scripts, packaging files, or writing skills — it will pick up the persona and instructions.
